# Musik latar (opsional)

Folder ini sudah berisi tiga lagu orisinal bawaan (Santai Sore, Petualangan Ceria, Fokus Tenang; digubah dan dirender dengan kode, bebas dipakai, tanpa kredit wajib). Untuk mengganti: hapus berkas itu dan/atau tambahkan lagu lain. Taruh berkas lagu di folder ini (`.mp3`, `.ogg`, atau `.m4a`). Saat dibuild, semuanya otomatis ikut ke dalam aplikasi
dan diputar bergantian (acak urutan awal, berulang). Jika folder ini tidak berisi lagu, aplikasi memakai musik sintetis.

- Pakai lagu bebas royalti dan **cek lisensinya** (mis. Pixabay Music, FreePD (CC0), incompetech (CC BY: wajib mencantumkan kredit)).
- Isi kredit yang diwajibkan lisensi di `MUSIC_CREDIT` pada `src/app/brand.ts` (muncul di Setting → Tentang).
- Ukuran: 1–4 MB per lagu sudah cukup. Beberapa lagu 2–3 menit lebih nyaman daripada satu lagu panjang.
